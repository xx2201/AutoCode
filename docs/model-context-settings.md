# 模型上下文窗口设置

右上角模型设置支持选择 64k、128k、200k、256k、512k、1M，或直接输入整数 token。
这是应用使用的窗口预算，不会改变服务商或模型的实际能力；请勿超过模型支持的上限。

保存路径：ModelSettingsModal → /api/model-config → Relay → Runner → web-model.json。
Runner 校验窗口大于配置的最大输出额度后持久化，并清理旧 manager；后续加载任务使用新预算。
正在执行任务时拒绝修改，不中途更换请求预算。没有修改旧历史或任务笔记。

固定计算策略（ContextManager.PREPARATION_PERCENT = 5）：

- 可用输入 I = 所选窗口 W − 最大输出 O。
- 提醒提前量与准备缓冲均为 floor(I × 5%)。
- 提醒线 = I − 两份准备预算；基础窗口结束线 = I − 一份准备预算。
- 输入硬边界 = I；模型可在提醒后保存笔记并主动 new_context。
- 占用仍由 Agent 的有效 provider usage 加新增消息估算提供；不取全量字符估算的较大值。

例如最大输出为 32,000：256,000 窗口在 201,600 提醒，212,800 进入缓冲，224,000 强制切窗；
1,000,000 窗口对应 871,200 / 919,600 / 968,000。页面显示实时计算结果，百分比不可编辑。
这些是本应用固定策略，不是声称复制了某个模型的官方预算默认值。
